# 闪填简历网站视觉规范

## Direction & Layout
面向首次安装浏览器扩展的求职新人，整体应像一份可信、清晰、能照着完成的产品说明书，而非复杂开发者文档。第一屏以“从下载到填表只需三步”的路径卡作为定义性视觉，并配合闪电品牌符号；参考浏览器原生设置页的清晰层级，但使用更鲜明的青绿色品牌面。桌面最大宽度 1180px，首屏采用 60/40 非对称布局；教程采用左侧步骤轨道、右侧详细说明。章节间距 96px，卡片间距 20px。移动端小于 768px 改为单栏，导航收拢为核心行动，页面边距 20px；平板 768–1024px 维持单栏教程；桌面 1024px 以上使用双栏。必须突出下载、安装地址、目录层级与“不会自动提交”；禁止深色赛博风、蓝紫渐变、玻璃拟态、虚构截图及未在 README 出现的操作。

## Tokens
主色 #0B7A68，深主色 #075E52，强调色 #F4B942，纸张背景 #F6F7F2，深色品牌面 #102A2A，卡片 #FFFFFF，正文 #17302D，次级文字 #5C706C，边框 #D8E2DE；成功 #18835E、提醒 #B76813、错误 #B93832。强调色仅用于闪电、步骤序号与少量提示。字体使用“Noto Sans SC”, “Microsoft YaHei”, sans-serif；展示标题 56/64px 800，移动端 38/46px；章节标题 34/44px 750；正文 16/28px 400；按钮 15/20px 700；说明 13/20px。间距基于 4/8/12/16/20/24/32/48/64/96；按钮圆角 12px，卡片 20px，代码块 12px，图标按钮为圆形。卡片边框 1px #D8E2DE，轻阴影 0 12px 32px rgba(16,42,42,.08)；粘性导航使用不透明浅背景与细边框，不使用模糊玻璃。

## Shared Patterns & States
顶部导航包含品牌、教程锚点与高对比下载按钮；主按钮深绿底白字，次按钮透明底深绿描边。步骤卡包含编号、标题、原文操作和必要提示；浏览器切换只改变地址及浏览器名称，不改变原始步骤。状态说明卡以“已填写/待确认/缺必填”三列展示。安全承诺使用深色整块区域。下载按钮下载中禁用并显示状态，失败时在按钮附近给出重试信息。悬停 160ms ease-out 轻微上移 2px；点击缩放 0.98；折叠内容 200ms。正文默认可见，不使用滚动后才显现。交互目标至少 44px，键盘焦点为 3px #F4B942 外圈，图标按钮提供可访问名称，颜色对比满足 WCAG AA。

## Media
本页以操作流程和浏览器界面式示意为主，不需要摄影或生成图片；避免虚构插件真实截图。允许使用 CSS 绘制的浏览器窗口、文件夹层级和状态标签作为教学辅助，不能替代 README 原文步骤。品牌闪电使用 lucide 图标，不制作 favicon 或额外图像资产。
